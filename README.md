# Mukesh Singh — Portfolio

Personal portfolio website of **Mukesh Singh**, Full Stack Developer based in Dehradun, India, and founder of [Add Spark Digital](https://addsparkdigital.site.je).

🔗 **Live site:** https://mukeshsingh1234.github.io

## About

A single-page animated portfolio built with plain HTML, CSS and JavaScript — featuring a 3D Three.js hero scene, scroll-reveal sections, a cursor-follow glow effect, and animated stats. Showcases skills, experience and live client projects.

## Sections

- **Hero** — 3D wireframe mountain scene with mouse parallax
- **Stats** — animated count-up numbers
- **Selected work** — live client projects with 3D tilt cards
- **Experience** — professional history
- **About & skills** — tech stack breakdown
- **Education**
- **Contact**

## Tech used

- HTML5 / CSS3 / vanilla JavaScript
- [Three.js](https://threejs.org/) for the 3D hero scene
- Google Fonts (Fraunces, Space Grotesk)
- Hosted on GitHub Pages
